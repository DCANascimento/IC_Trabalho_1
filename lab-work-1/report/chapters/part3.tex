\section{Our Implementation}

Similarly to the previous codec, this one was split into:

\begin{itemize}
    \item \textbf{wav.cpp} still handles WAV file reading and writing.

    \item \textbf{mdct.cpp + fft.cpp} apply the sine window, handles block overlapping, and computes the MDCT/DCT efficiently by folding the input into a DCT-IV using an internal FFT.
    
    \item \textbf{transform.cpp} selects the transform and validates the block size.
    
    \item \textbf{codec.cpp} contains more aggregated operations, such as the quantizer (later implemented with deadzone + centroid offsets), per-block Mid/Side decision and context-adaptive Rice parameter (also implemented in a later version), file format LSY6 and rate control.
    
    \item \textbf{bitstream.hpp} provides low-level bit manipulation via `BitWriter` and `BitReader`. It packs variable-length Rice codes, the `last` non-zero position markers, and stereo Mid/Side flags tightly into the output byte stream. It also contains calls the functions for the zigzag and rice encoding operations.
    
    \item \textbf{bytes.hpp} provides lightweight utility functions and helper classes for low-level binary file I/O and little-endian data manipulation in memory.
    
    \item \textbf{wav\_lossy\_enc.cpp / wav\_lossy\_dec.cpp / wav\_snr.cpp} are the three main programs for execution.
\end{itemize}

\section{Final Adjustments}

Like with the lossless encoder, we were already expecting that block encoding would end up being implemented, to improve our compression results, as well as splitting both channels (in the case of stereo) into MID and SIDE channels. So for the final version of the lossy codec, besides those changes, we have also identified and implemented other possible improvements:

\begin{enumerate}
    \item \textbf{Quantization and centroid reconstruction:} We replaced simple uniform scaling with an advanced deadzone quantizer, which effectively eliminates faint background noise, and paired it with centroid reconstruction parameters, which reduce the error that arises from the deadzone quantization.

    \item \textbf{Context based Rice encoding:} While before we used a single global parameter for an entire block, often resulting in inefficient bit distribution, we now dynamically calculate and predict an optimal k parameter for every single coefficient.
\end{enumerate}

After implementing those changes, we observed a noticeable improvement, as seen in Table \ref{tab:incremental_improvement}, specially from the context-adaptive Rice parameter k. Each row of the table is cumulative, and after all the changes done we obtained a BD-rate improvement of about -32.7\% and BD-SNR improvement of +8.056dB.
